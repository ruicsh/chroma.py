# chroma.py

A CLI tool that generates dual-theme (light/dark) design tokens from a single brand color, using the **OKLCH color space**.

`chroma.py` derives a deterministic 12-step neutral scale and WCAG-checked contrast pairings from one hex value, and emits them under multiple naming taxonomies.

---

## Quick Start

```bash
# Clone the repository
git clone https://github.com/ruicsh/chroma.py.git
cd chroma.py

# Compile a full dual-theme token system from a single brand hex
uv run python -m chroma 6366f1

# Emit plain CSS custom properties instead of the default Tailwind stylesheet
uv run python -m chroma 6366f1 --format css --output tokens.css
```

---

## How it works

- **OKLCH conversion:** Colors are converted to Lightness, Chroma, and Hue (H), so hue shifts keep perceptual brightness uniform.
- **12-step scale:** The neutral and brand ramps use lightness curves mapped to UI layout layers.
- **Contrast calibration:** Foreground-to-background pairings are interpolated to clear **WCAG AAA contrast ratios (≥ 7:1)**.

---

## Command Line Interface

```bash
uv run python -m chroma HEX [FLAGS]
```

The single required argument is the brand **hex** color (e.g. `6366f1`); its hue angle is extracted and locked as the anchor for the entire token system.

### Options

| Flag | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `-t`, `--taxonomy` | `str` | `atmos` | Target token naming taxonomy contract (`atmos`, `m3`, `atlassian`, `slds`, `spectrum`). |
| `-f`, `--format` | `str` | `tailwind` | File serialization compilation format (`json`, `tailwind`, `tailwind-v3`, `css`, `ts`, `dtcg`, `figma`, `sass`, `less`, `stylus`, `preview`). |
| `-o`, `--output` | `str` | `stdout` | Target file destination path for the compiled token artifact. |
| `--preserve-vibrancy` | `flag` | `off` | Lock the brand accent exactly and solve the on-color label for AAA instead of shifting accent lightness. |

---

## Supported Taxonomies

Select a token naming scheme with the `--taxonomy` flag. The generated scale is identical across taxonomies; only the token keys change:

- **`atmos` (Default):** Systematic UI naming conventions (`bg-surface-default`, `text-foreground-primary`).
- **`m3`:** Google Material Design 3 contextual color role pairs over a linear sequential primitive ramp (`sys-color-surface-container-low`).
- **`atlassian`:** Nested object dot-notation layout optimized for dense SaaS dashboard configurations (`background.elevation.surface`).
- **`slds`:** Salesforce Lightning Design System 2 decoupled structural styling hooks (`color-neutral-base-20`).
- **`spectrum`:** Adobe Spectrum immutable multi-package core naming tokens (`core-color-background-layer-low`).

## Multi-Format Compilation

The format engine outputs the chosen taxonomy cleanly across multiple development configurations:

### CSS Custom Properties (`--format css`)

```css
/* Generated by chroma.py v1.2.0 — semantic theme tokens (atmos). */
:root {
  /* The 12-Step Mathematical Gray Ramp */
  --neutral-scale-1: #fbfcfe;
  --neutral-scale-2: #f7f8fc;

  /* Semantic Structural Mapping Matrix */
  --bg-surface-root: var(--neutral-scale-1); /* app canvas background */
  --bg-surface-default: var(--neutral-scale-2); /* layout panels & content cards */
}

.dark {
  --neutral-scale-1: #0c0d12;
  --neutral-scale-2: #111218;
  --bg-surface-root: var(--neutral-scale-1);
  --bg-surface-default: var(--neutral-scale-2);
}
```

Global ramp values are concrete hex; semantic tokens chain through `var()` so the raw globals stay the single source of truth.

### JSON Token Dictionary (`--format json`)

```json
{
  "meta": { "input": "6366f1", "taxonomy": "atmos" },
  "global": {
    "dark": { "neutral-scale-1": "#0c0d12" },
    "light": { "neutral-scale-1": "#fbfcfe" }
  },
  "semantic": {
    "dark": { "bg-surface-root": "#0c0d12" },
    "light": { "bg-surface-root": "#fbfcfe" }
  },
  "oklch": {
    "semantic": {
      "light": { "bg-surface-root": "0.9909 0.0029 264.54" }
    }
  }
}
```

### TypeScript Definition Module (`--format ts`)

```typescript
/* Flat semantic palette. */
export const chromaTheme = {
  light: { bgSurfaceRoot: '#fbfcfe', bgSurfaceDefault: '#f7f8fc' },
  dark: { bgSurfaceRoot: '#0c0d12', bgSurfaceDefault: '#111218' },
} as const;

export type ChromaTheme = typeof chromaTheme;
```
